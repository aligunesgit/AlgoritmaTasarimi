!!! info "Durum"

## ❔ Öğrenme hedefleri

Bu modülün sonunda öğrenci:

* Tekrarlanan işleri fonksiyonlara ayırmak
* Parametre alan ve değer döndüren fonksiyonlar yazmak
* Yerel ve global kapsamı ayırt etmek
* Fonksiyonları pytest ile test etmek

## 📚 İçerik

1. Fonksiyon nedir? Neden kullanılır?
2. Akış şemasında alt program (predefined process) sembolü
3. Python'da fonksiyon tanımlama (def)
4. Parametreler ve dönüş değeri
5. Kapsam (scope)
6. Hazır fonksiyonlar ve modüller
