# 🔀 M7 - Karar Yapıları

<p align="center"><em>Hafta 7</em></p>

Karar yapıları: tek, iki ve çok yönlü seçim; iç içe koşullar.

!!! info "Durum"

    Bu modülün içeriği hazırlanıyor. Aşağıdaki başlıklar planlanan kapsamı gösterir.

## ❔ Öğrenme hedefleri

Bu modülün sonunda öğrenci:

* Karar gerektiren problemleri akış diyagramında göstermek
* if / elif / else yapılarını doğru kullanmak
* İç içe koşulları ve mantıksal operatörleri birleştirmek
* Sınır değerleri (edge case) test etmek

## 📚 İçerik

1. Karar yapısı nedir?
2. Tek yönlü seçim (if)
3. İki yönlü seçim (if-else)
4. Çok yönlü seçim (if-elif-else, match-case)
5. İç içe koşullar
6. Sınır değerlerin test edilmesi
