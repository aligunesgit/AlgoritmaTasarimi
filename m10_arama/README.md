# 🔍 M10 - Arama Algoritmaları

<p align="center"><em>Hafta 11</em></p>

Arama algoritmaları: doğrusal arama ve ikili arama; listelerle çalışma.

!!! info "Durum"

    Bu modülün içeriği hazırlanıyor. Aşağıdaki başlıklar planlanan kapsamı gösterir.

## ❔ Öğrenme hedefleri

Bu modülün sonunda öğrenci:

* Listelerle temel işlemleri yapmak
* Doğrusal aramayı akış diyagramı ve Python ile uygulamak
* İkili aramanın çalışma mantığını ve ön koşulunu açıklamak
* İki arama yönteminin adım sayısını karşılaştırmak

## 📚 İçerik

1. Listeler (diziler) ile çalışma
2. Arama problemi
3. Doğrusal arama (linear search)
4. İkili arama (binary search)
5. Karşılaştırma: kaç adımda buluruz?
