# 📶 M11 - Sıralama Algoritmaları

<p align="center"><em>Hafta 12</em></p>

Sıralama algoritmaları: kabarcık, seçmeli ve eklemeli sıralama; birleştirmeli sıralamaya kısa bakış.

!!! info "Durum"

    Bu modülün içeriği hazırlanıyor. Aşağıdaki başlıklar planlanan kapsamı gösterir.

## ❔ Öğrenme hedefleri

Bu modülün sonunda öğrenci:

* Sıralama probleminin neden önemli olduğunu açıklamak
* Kabarcık, seçmeli ve eklemeli sıralamayı elle ve kodla uygulamak
* Algoritmaların karşılaştırma/yer değiştirme sayılarını ölçmek
* Birleştirmeli sıralamanın böl-fethet fikrini tanımak

## 📚 İçerik

1. Sıralama problemi
2. Kabarcık sıralama (bubble sort)
3. Seçmeli sıralama (selection sort)
4. Eklemeli sıralama (insertion sort)
5. Birleştirmeli sıralamaya bakış (merge sort)
6. Python'un hazır sıralaması: sorted()
